Estruturas de Dados

Estruturas de Dados estuda maneiras de organizar informações na memória para que operações como inserir, remover, pesquisar e percorrer elementos sejam realizadas de forma adequada. A escolha da estrutura influencia o desempenho e a clareza dos algoritmos.

Visão geral

Estruturas de Dados estuda maneiras de organizar informações na memória para que operações como inserir, remover, pesquisar e percorrer elementos sejam realizadas de forma adequada. A escolha da estrutura influencia o desempenho e a clareza dos algoritmos.

Assuntos centrais

  • Tipos abstratos de dados e análise de custo das operações
  • Vetores, listas encadeadas e suas variações
  • Pilhas e filas
  • Árvores e grafos
  • Algoritmos de busca, ordenação e noções de complexidade

Conexão com a prática

Implementar uma estrutura e comparar o custo de suas operações permite entender por que uma solução é mais adequada que outra em determinado cenário, considerando volume de dados e tipos de acesso.
