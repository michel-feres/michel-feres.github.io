Técnicas Avançadas de Programação Web e Mobile

A disciplina aborda técnicas para desenvolver aplicações acessíveis pela web e por dispositivos móveis. O estudo envolve a comunicação entre interfaces e serviços, a organização da aplicação e as particularidades de diferentes dispositivos.

Visão geral

A disciplina aborda técnicas para desenvolver aplicações acessíveis pela web e por dispositivos móveis. O estudo envolve a comunicação entre interfaces e serviços, a organização da aplicação e as particularidades de diferentes dispositivos.

Assuntos centrais

  • Arquitetura de aplicações web e mobile
  • Desenvolvimento de interfaces responsivas e adaptáveis
  • Comunicação cliente-servidor e consumo de APIs
  • Integração com serviços e persistência de dados
  • Experiência do usuário, testes e publicação de aplicações

Conexão com a prática

Uma aplicação que consulta uma API e apresenta os dados em diferentes tamanhos de tela permite exercitar integração, tratamento de respostas, responsividade e consistência da experiência.
